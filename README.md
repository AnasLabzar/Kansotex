# Kansotex

Site vitrine de Kansotex — textile **In & Outdoor**, tissus haut de gamme, linge de maison, linge de lit et linge de bain.

Inspiré de la direction artistique éditoriale de [Maison Nicole](https://www.maison-nicole.com/) (espace, serif mixte, navigation uppercase), avec l’identité Kansotex.

## Développement

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

Le téléphone, l’email et les réseaux dans `lib/content.ts` sont des placeholders à remplacer par les coordonnées réelles.
